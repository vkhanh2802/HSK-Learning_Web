# Dữ liệu gốc

`hsk1.json` … `hsk4.json` là danh sách từ HSK 2.0 (mỗi file chỉ chứa từ mới của cấp đó), tải nguyên bản từ
<https://github.com/drkameleon/complete-hsk-vocabulary> — thư mục `wordlists/exclusive/old/`, giấy phép MIT.
Không sửa tay các file này; mọi bổ sung (pinyin chuẩn, nghĩa Việt, ví dụ) nằm trong `data/vocab/`.

`hsk2012-l2.tsv` … `hsk2012-l4.tsv` là danh sách **chính thức HSK 2012** cấp 2–4 (file `HSK Official With Definitions 2012 L2–L4.txt`
trong <https://github.com/glxxyz/hskhsk.com>, thư mục `data/lists/`, giấy phép MIT). Mỗi dòng: giản thể, phồn thể, pinyin số,
pinyin có dấu, nghĩa tiếng Anh (cách nhau bằng tab). HSK2–4 dùng các file này; HSK1 vẫn dùng `hsk1.json`.
